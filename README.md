# 桌面盒子 DeskBoxes

> **功能清单 / 迁移核对基线：[`docs/功能清单.md`](docs/功能清单.md)**
> 旧版改新版、或重写前先按这份清单逐条核对，尤其第 11 节的「已拍板决策」。

把桌面软件按分类放进一个面板里：**每个盒子 3×3 方形格子、名称在正下方、超出自动分页**，像手机桌面。

- 单文件 exe，**56 KB**，.NET Framework 4.8（Win10/11 自带），双击即用
- 常驻内存 **约 30 MB**（Fences 50–80 MB、DeskBox 80–150 MB）
- 不联网、无遥测、不需要管理员权限

## 形态

```
┌──────────────────────────────────────────────────────────┐
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       ⚙      │ ← 右上角设置
│  │ □ □ □    │  │ □ □ □    │  │ □ □ □    │              │
│  │ □ □ □    │  │ □ □ □    │  │ □ □ □    │  ← 3×3 方形  │
│  │ □ □ □    │  │ □ □ □    │  │ □ □ □    │              │
│  └──────────┘  └──────────┘  └──────────┘              │
│   ◀ 开发工具 ▶1/2   AI 工具    办公协作                  │ ← 名称在下 + 分页
└──────────────────────────────────────────────────────────┘
```

- 面板**顶部有标题**（默认「桌面应用」，可改），右上角是**汉堡菜单**（三条横线）
- 面板尺寸**随盒子数量自适应**，最多显示 3 行，超出滚动；上下留有内边距
- 每个盒子固定 **3 列 × 3 行 = 9 格**；超过 9 个在盒子内**分页**
  页码紧跟在盒子名后面（如「开发工具 1/2」），**点盒子名翻下一页**，鼠标停在盒子上滚滚轮也行
- 盒子内**按使用频次 + 新鲜度排序**：30 天半衰期的衰减分，常用且近期用过的自动靠前
- **面板背景色和透明度可自己调**（⚙ → 面板背景色 / 面板透明度）
- 图标名称、盒子名都带暗描边

## 操作

| 操作 | 效果 |
|---|---|
| 把快捷方式/文件拖到某个盒子 | 加入该盒子（拖到哪个盒子就进哪个） |
| **拖动图标到另一个盒子** | 移过去（落在哪个盒子就进哪个） |
| **拖动盒子到另一个位置** | 交换顺序 |
| 双击图标 | 启动；双击盒子空白处无动作 |
| **点盒子名称** | 翻到下一页（到底回第一页）；滚轮停在盒子上也行 |
| 拖面板空白处 | 移动整个面板 |
| **右上角 ☰** | 自动归类 / 创建盒子 / 重命名标题 / 面板背景色（7 色预设 + **自定义颜色**）/ 面板透明度（39%–100%）/ 图标大小 / 字号 / 显示名称 / 刷新图标 |
| 右键图标 | **打开 / 以管理员身份运行 / 打开方式 / 属性 / 固定到任务栏·开始**（原生能力）/ 改显示名 / 移到盒子 / 移除 |
| 右键盒子 | 添加应用 / 重命名 / 配色 / **解散** |
| 右键面板空白 | 同 ⚙ 菜单 |

**解散盒子**：应用不会丢，会落到面板的「未分组」区域（虚线框），可以再拖进别的盒子。

## 使用频次（衰减排序）

每次双击启动应用都会记一次，写入 `boxes.json` 的 `clicks`（`score` + `last` 时间戳）。

排序用的是**带时间衰减的分数**，不是简单的总次数：

- 每次点击：`score = score × 0.5^(距上次使用天数 / 30) + 1`
- 排序时：`有效分 = score × 0.5^(距今天数 / 30)`，再按 `log(1+有效分)` 分档（约 15% 一档）
- **半衰期 30 天**：一个月前的使用还剩 50% 权重，两个月前剩 25%
- **同档不换位**：只有高出约 15% 以上才会升档，避免微小差异导致来回跳
- 同档内保持你拖动的先后顺序

效果：天天用的稳定在前，最近用得多的会上升，长期不用的慢慢下沉。
想清零：删掉 `boxes.json` 里的 `clicks` 数组即可。

## 自动归类

⚙ → 自动归类（或托盘菜单 → 自动整理桌面）：

1. 扫描**两个桌面**（`C:\Users\<你>\Desktop` + `C:\Users\Public\Desktop`）
2. 弹预览，列出每个盒子会收哪些
3. 确认后把快捷方式移入 `%APPDATA%\DeskBoxes\Vault\<盒子>\`
4. 按文件名重新分类，**所有应用必定落在某个盒子里**（匹配不上进「其他」）
5. 「此电脑」「回收站」自动放进**系统工具**

内置 10 类规则：开发工具 / AI 工具 / 聊天通讯 / 办公协作 / 浏览器 / 截图录屏 / 远程连接 / 系统工具 / 虚拟机 / 娱乐。
规则在 `src/AutoOrganizer.cs` 的 `Rules` 表，按关键词匹配，可自行增删。

> **重要**：自动归类**不记忆**你手动拖出来的布局。拖动排序、跨盒子移动只在当前会话生效，下次自动归类会按规则重排。这是刻意设计——让规则永远是可预期的。

**还原**：托盘菜单 →「还原本地快捷方式到桌面（N）」，按日志把文件移回原位。

## 数据存放在哪

| 位置 | 内容 | 为什么在这 |
|---|---|---|
| `%APPDATA%\DeskBoxes\boxes.json` | 面板布局、分区、条目 | 配置 |
| `%APPDATA%\DeskBoxes\Vault\` | 自动整理时移入的快捷方式实体 | 用户数据 |
| `%APPDATA%\DeskBoxes\apikey.txt` | DeepSeek API Key | 配置 |
| `%APPDATA%\DeskBoxes\shortcuts.txt` | 快捷键速查表 | 配置 |
| **`<exe目录>\data\history.csv`** | 余额采样历史（3 天） | **不能放 AppData**：exe 从 Low 完整性目录启动，写 AppData 被 UIPI 拒绝 |

> 如果换成别的杀毒软件且 AppData 能写，也可以把历史数据挪回去，改 `BalanceData.HistoryPath` 即可。

## 已知问题：托盘图标不显示（暂缓）

**现象**：程序运行时，任务栏托盘区（含 `^` 溢出面板）都**看不到**「桌面盒子」图标。

**已排除**：
- 代码确实执行（日志确认 `NotifyIcon.Visible = true` 成功返回）
- 图标不是元凶（换 `SystemIcons.Application` 系统图标同样不显示）
- 无托盘相关组策略限制
- 进程在正常用户会话（Session 1），非服务/隔离会话
- 无 360 安全卫士/火绒拦截托盘行为（只有 360huabao 壁纸在跑）
- `NotifyIconSettings` 注册表里没有本程序的项（系统从未真正接纳这个图标）

**已尝试无效**：
- 自定义内存图标 → 写 `.ico` 文件再加载 → 从 exe 提取图标（`/win32icon` + `ExtractAssociatedIcon`）
- 先设菜单再 `Visible=true` / 先 `Visible=true` 再设菜单
- 清理所有残留实例后干净启动

**已查明的根因（2026-10-26）**：`D:\ai_code` 目录被标记为 **Low 完整性级别**
（`icacls "D:\ai_code"` 显示 `Mandatory Label\Low Mandatory Level:(OI)(CI)(NW)`）。
从这里启动的 exe 继承 Low，写 Medium 级别的 `%APPDATA%` 会被 Windows UIPI 拒绝，
报 `UnauthorizedAccessException`，但 `icacls` 显示的权限是 FullControl——看起来像权限没问题。
对照：同一文件用 Python 写就成功（Python 进程是 Medium），往 exe 同目录写也成功。
系统 Defender 的受控文件夹访问为**关闭**（CFA=0），本机也未安装火绒/360 安全卫士。

两条解法：
1. **（当前采用）数据放 exe 同目录**：`<exe>\data\history.csv`，运行时零 AppData 写入。
2. **（根治，可选）修目录标签**（改的是 `D:\ai_code` 整个目录，需要管理员权限）：
   ```
   icacls "D:\ai_code" /setintegritylevel "(OI)(CI)Medium"
   icacls "D:\ai_code" /setintegritylevel Medium /T
   ```
   改完重编，exe 继承 Medium，写 AppData 恢复正常。注意这会影响该目录下所有项目。

**当前结论**：托盘图标改为从 exe 提取（`ExtractAssociatedIcon`，零文件写入）后仍然不显示，
说明写文件被拦只是原因之一，另有未查明的原因。`NotifyIcon.Visible=true` 返回成功但系统未注册。

**不影响功能**：所有设置入口在**面板右上角 `☰` 按钮**里（自动归类 / 创建盒子 / 标题 / 背景 / 透明度 / 图标大小 / 字号 / 开机自启开关在托盘菜单，可改到 ☰）。

**后续可试**：改用 `Shell_NotifyIcon` 原生 API（能拿到失败错误码）、或把托盘交给独立的小宿主进程。

## 托盘图标看不到？

Windows 11 默认把新程序的托盘图标收进**溢出区**（任务栏那个 `^` 里）。两种办法让它常显：

1. 点任务栏的 `^` → 把「桌面盒子」图标**拖到任务栏上**
2. 设置 → 个性化 → 任务栏 → **其他系统托盘图标** → 把「桌面盒子」打开

> 程序本身没有问题：图标创建时 `visible=True`，只是系统把它折叠了。Windows 不开放"程序自己强制常显"的接口。

## 桌面上的「此电脑」「回收站」

桌面那两个是 **Windows 系统图标**，不是文件，任何整理工具都搬不走它们。
盒子里的那两个是独立入口，点击用 `shell:::{CLSID}` 正常打开。

如果不想在桌面重复看到，可以关掉系统图标：
**桌面右键 → 个性化 → 主题 → 桌面图标设置 → 取消勾选「计算机」「回收站」**

## 数据与安全

```
%APPDATA%\DeskBoxes\
├─ boxes.json          面板位置、盒子、每个盒子的应用
├─ organize-log.json   每次移动的「原路径 → 新路径」，还原靠它
└─ Vault\<盒子>\       快捷方式实际存放
```

- 只存路径引用，**不会复制或删除你的文档**
- 重名自动加序号，绝不覆盖
- 单个文件被占用失败不影响其他

## 编译

双击 `build.bat`（Windows 自带 csc.exe，无需 Visual Studio）。

## 已知限制

- 按 `Win+D` 显示桌面时面板会一起隐藏（普通窗口行为），再按一次或双击托盘图标恢复
- 盒子内超过 9 个才分页；不足 9 个时盒子保持同样的方块尺寸（避免参差）
