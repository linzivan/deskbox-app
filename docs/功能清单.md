## 11. 已拍板的产品决策（迁移时不可丢）

1. **一个进程托管多个盒子**（主面板 + 余额 + 快捷键 + Hermes 四个独立浮窗），托盘统一管理，不拆成多个 exe。
2. **排序用方案 E**：30 天半衰期指数衰减 + 约 15% 相对分档 + 同档原序；**不加「常用置顶」**。
3. **收纳必须闭环**：程序不运行 → 桌面正常显示图标；程序运行 → 收进盒子；退出/关机 → 释放回来。
4. **快捷键不用记事本**：盒子内「+」增删、点条目编辑、按键自动捕获、`Fn` 可手动输入。
5. **透明度范围 20%–100%**，所有盒子记住位置与尺寸。
6. **UI 全中文**。
7. **数据脱敏**：`apikey.txt` / `shortcuts.txt` / `history.csv` / `*.cfg` 不进仓库，只提交示例文件。
8. **层级规则**：只在桌面在前台时置顶；普通应用在前台不遮挡；弹菜单必须在所有盒子之上。
9. **用户意图优先**：主动隐藏的盒子不能被程序自己显示回来。
10. **Hermes 盒子没数据就整盒隐藏**，不显示空壳。

diff <(grep -o 'DataMember(Name = "[a-zA-Z]*")' 旧版/src/BoxConfig.cs | sort) \
     <(grep -o 'DataMember(Name = "[a-zA-Z]*")' 新版/src/BoxConfig.cs | sort)
